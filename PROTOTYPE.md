# Smart Parking Prototype

A standalone, static prototype for exploring a smart parking experience in Pakistani cities.

## Included

- Example parking zones and availability counts (illustrative only)
- Browser location permission flow
- Google Maps driving directions links
- Operator snapshot with sample metrics

## Run locally

Open `index.html` in a browser. Location access depends on the browser and secure-context rules; serve the folder from localhost if the browser blocks geolocation from a local file.

## Important

This prototype is not connected to live parking operators, sensors, cameras, payments, or a parking database. Availability, places, and operator figures are examples. Google Maps directions open externally; no Maps Platform API key is embedded.
